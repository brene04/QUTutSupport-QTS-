## Say Hello to QUTutSupport (QTS)

A mini full-stack web application for student-tutor booking support created using Amazon EC2, React.js, Node.js, Express.js, and MongoDB.

## Live Demo URL
http://16.176.231.168

## Functionalities
- Registering/logging in users with JSON Web Tokens (JWT)
- Making tutoring bookings using unique tutorID
- Viewing all bookings
- Editing/rescheduling bookings
- Deleting bookings

## Technologies Used 
(Frontend)
- React.js
- Axios

(Backend)
- Node.js
- Express.js
- MongoDB 
- JSON Web Token (JWT) for Authentication

## CI/CD Pipeline
- GitHub Actions for automated tests and deployments
- Self-hosted runner on AWS EC2
- Process management with PM2
- Nginx as reverse proxy server

## Deployment
- Running on AWS EC2 instance (Ubuntu)
- EC2 Public IP: 16.176.231.168

## Backend Testing
- Mocha and Chai for unit tests
- CRUD functionalities for bookings tested
